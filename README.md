# Web-Musical-Player
It is a visually stunning, responsive web-based music player featuring a modern Glassmorphism UI. Designed with a focus on aesthetics and user experience, it brings a "Cyberpunk" vibe to your local music library.


✨ Features
Modern UI: A clean, dark-themed interface with vibrant neon accents.

Dynamic Library: Easily browse through your playlist on the sidebar.

Interactive Controls: Smooth play/pause functionality, track skipping, and volume adjustment.

Progress Tracking: Visual seek bar to track your music's progress.

Glassmorphism Design: Uses backdrop filters and soft shadows for a premium layered look.

🛠️ Built With
HTML5: For the semantic structure of the player.

CSS3: Custom styling featuring Flexbox, CSS Grid, and advanced gradients.

JavaScript: Powering the audio playback logic and UI interactions.
